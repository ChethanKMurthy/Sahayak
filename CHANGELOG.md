## [0.1.0] — 2026-06-13
### Added
- **Discover → Execute → Track** flow: document capture, a deterministic eligibility
  rules-gate, voice-first form fill, consent teach-back, submittable PDF, checklist,
  reference number and reminders.
- Differentiators: provenance/confidence tiers, consistency engine, dependency chains,
  entitlement surprises, and a fair-price meter.
- 7 languages: Hindi, English, Kannada, Tamil, Telugu, Marathi, Bengali.
- FastAPI backend, Next.js web app, Flutter Android app, shared knowledge base.
- All-on-Vercel deployment (stateless backend, PDFs stored in Postgres).
